***Chilpatl*** is a Nahuatl word meaning **red wasp or hornet**.

The name **Chilpa** comes from it.

* **Pronunciation / variant:** Derived from the Classical Nahuatl root associated with *chilpatli* or *chilpatl*.
* **Meaning:** Literally refers to a **red wasp** or **hornet** (*avispa roja* / *avispón*).
