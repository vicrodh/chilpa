# dst-decoder 0.1.2

Chilpa uses `dst-decoder` 0.1.2 only to decode MPEG-4 Direct Stream Transfer
(DST), the lossless compression most Super Audio CDs are pressed with. The
crate is under the Apache License 2.0: `Apache-2.0-dst-decoder.txt` is the
`LICENSE` file it ships.

Its README says it is based heavily on the MPEG-4 DST reference
implementation, and reproduces the notice of that implementation's authors.
That notice is in `dst-decoder-upstream-NOTICE.txt`, as the crate's README
gives it. Both files are here so that neither depends on a link.
